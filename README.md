# 🤖 Smart Git-Commit AI Generator

An automated terminal utility that analyzes your local `git diff` changes and suggests highly professional, semantic commit messages instantly.

## 🚀 Features
- **Zero Configuration:** No API keys or external setups required out of the box.
- **Smart Analysis:** Inspects insertions, deletions, and structural code updates dynamically.
- **Time Saver:** Helps developers write clean, professional Git documentation instantly.

## 💻 Installation & Usage

```bash
# Clone the repository
git clone https://github.com

# Run the utility tool
python ai_commit.py
```
